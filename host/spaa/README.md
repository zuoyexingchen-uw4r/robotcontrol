# 图传上位机（SPAA 布局）

独立的电脑端程序：接手机图传 → 硬解 → GL 纹理显示 → 叠加一层"自行防空炮"式的
信息面板（车辆信息 / 测距环 / 雷达 / 姿态 / 弹药 / 链路统计）。

> 只借信息架构，不抄视觉风格。每个面板都能对应到车上的真实数据源，
> 没有数据的项就显示 `--` 或"无雷达数据"，不编造。

## 为什么另起一个，而不是改现有 HUD

| 现有实现 | 状态 |
|---|---|
| `host/video_host.py` | 协议**对**：GameStream 32B 头 → RS-FEC → 组帧。但只有终端统计 + 外挂 ffplay 窗口，没法叠加 |
| `pc_hud/`（PyQt HUD） | 界面齐，但 `warhud/stream.py` 让 ffmpeg **直收 UDP 裸流**（默认 31000）。手机端只发 GameStream 封包（默认 46000），端口和封装都对不上 → 永远等不到画面 |

所以这里把 `video_host.py` 里验证过的接收内核抽出来（`rx_video.py`），
配一套 GL 纹理渲染 + 叠加层，不动现有 HUD。

## 目录

| 文件 | 作用 |
|---|---|
| `rx_video.py` | UDP 收包、RTP/NV 头解析、FEC 擦除解码、多块组帧、关键帧请求、录制 |
| `decoder.py` | ffmpeg 子进程：硬解（d3d11va）优先，3 秒无输出自动回退软解 |
| `rx_aux.py` | 雷达点云 + 主控遥测（UDP 8768 + RS-FEC）、手机视觉结果（UDP 31001） |
| `geometry.py` | 相机模型：地面等距环投影、光轴落地距离、地平线 |
| `hud.py` | 叠加层绘制（分区见下） |
| `window.py` | 主窗口：GL 纹理 quad + QPainter 叠加 + 快捷键 |
| `config.py` | `~/.spaa/config.json`，含相机内参与告警阈值 |
| `selftest.py` | 纯逻辑自测 28 项 |
| `e2e_test.py` | 端到端：ffmpeg 造流 → 按 GameStream 打包 → 本机收 → 解码 → 截图 |

## 运行

```bash
# 依赖：PyQt5 / PyOpenGL / ffmpeg
python host/spaa_host.py --check      # 检查依赖与端口
python host/spaa_host.py --selftest   # 28/28
python host/spaa_host.py              # 启动
```

手机端不用改代码，只要「图传/桥接设置」里的视频端口和本机一致（默认 46000），
编码选 H.264（选 H.265 就把 `~/.spaa/config.json` 的 `codec` 改成 `hevc`）。

## 布局与数据来源

| 区块 | 位置 | 数据源 |
|---|---|---|
| 顶栏 | 顶部 | `GameStatus`（局号/阶段/倒计时/红蓝比分）+ `TargetStatus`（高地、基地掩码 → 4 段血条） |
| 参数列 | 左上 | 主控 `temp_0_1c / voltage_mv / current_ma`，超阈值转黄/红 |
| 测距环 | 画面中央 | 相机内参 + 安装高度/俯仰角，投影出 2/4/6/8m 四道参考环 |
| 目标距离环 | 画面中央 | 视觉 `track.dist_mm` 单独一圈高亮（黄色），准星右侧读 `◆ 2.4m` |
| 准星 + 俯仰刻度 | 中央 | 光轴；读数由 `mount_pitch + atan((v-cy)/fy)` 给出 |
| 目标框 | 画面 | 视觉 UDP 31001 的 `targets[]`（cx/cy/w/h/conf + dist_mm） |
| 扇形雷达 | 右侧 | 激光点云（`angle/dist/intensity`），8m 四环，扫描角 90~360 可配，带缩放 |
| 稳定器 | 左下 | 车辆俯视按 `imu_yaw` 转向，炮管指向 `track.yaw_deg`；三行：`gear` / `rpm_l,r` / `speed_mmps` |
| 武器栏 | 底部 | 7 个功能格（3~9），选中态绿框，长按项底部有进度条 |
| Toast | 中上 | 官方命中/罚时/红黄牌，由 `TargetStatus` / `RobotStatus` 的掩码差分产生 |
| 告警 | 底部中间 | 急停位、过温、σ_d/d>25%、视频中断 |

### 赛事服务器（MQTT）

`game_state.py` 已实现状态缓存与差分：

- 服务器 `192.168.1.2:3333`，MQTT + Protobuf v3，topic 即消息名，1 Hz
- `GameState.apply(topic, fields)` 是网络层唯一的接入点：反序列化后的 dict 丢进来即可
- 倒计时按收到时刻做本地插值，1 Hz 刷新不会跳格
- 命中 toast 靠**掩码差分**：`TargetStatus` 只给位图，保存上一秒的掩码逐位对比才知道"哪片刚被打中"

网络层（paho-mqtt + `protoc` 生成的类）还没接。没接之前 `MockSource` 会每 4~9 秒随机
产生一次命中/罚时，用来验证界面与 toast。

> **稳定器三行全部取真车数据，不做任何换算模型**：`gear` 是电机 PWM 占空比上限，

> `speed_mmps` 是主控上报的真实车速（显示时只做 mm/s→km/h 的单位换算）。
> 主控暂未上报时显示 `--`，不会用轮径/减速比去猜。

### 主控字段的两个约定

原 `LASER_PROTOCOL.md` 里 `fields[14..15]` 是 `res*` 预留位，上位机侧已启用：

| idx | 名 | 含义 |
|---|---|---|
| 14 | `gear` | 档位 = 电机 PWM 占空比上限 |
| 15 | `speed_mmps` | 真实车速，mm/s，倒车为负（i16 上限 ±32.7 m/s） |

电控侧按这个语义填即可；若暂时没有，填 0，界面会显示 0 而不是乱数。

## 相机标定（测距环准不准全看这个）

测距环是纯几何投影，参数错了会整体偏。改 `~/.spaa/config.json` 的 `camera`：

```json
"camera": {
  "fx": 1000.0, "fy": 1000.0, "cx": 640.0, "cy": 360.0,
  "mount_h_mm": 300.0, "mount_pitch_deg": 10.0,
  "ring_step_mm": 1000, "ring_max_mm": 8000
}
```

调法（车放平地，镜头对着 2m / 4m 处的实际标记）：

1. **`mount_h_mm`**：先调它，让画面里环的**横向宽度**对上实际距离；
2. **`mount_pitch_deg`**：再调它，让环在中轴上的**交点高度**对上；
3. **`fx/fy`**：镜头视场角。1280×720 下常见 900~1100，偏差表现为近处准、远处越差；
4. **`cx/cy`**：画面中心，一般就是宽高的一半，换了裁切/缩放才需要改。

`fx≈fy` 时环是正圆透视；若两者差很多，环会变成明显椭圆，说明参数抄错了。

## 已知限制 / 待办

- **赛事服务器网络层未接**：`game_state.apply()` 的接口已就位，缺 paho-mqtt + protobuf 反序列化那一段。
- **断电/重启只弹提示，还没下发**：需要主控下行 `cmd` 位（bit5 重启 / bit6 断电），等电控定字段。
- **雷达 0° 基准未标定**：点云按雷达自身角度画，还没和车头对齐。
- **`gear` / `speed_mmps` 待电控填**：字段已在上位机启用，主控填 0 时界面显示 0。
- **弹药是规则计数**，不是真实余弹。
- **未真机联调**：FEC 实际丢包恢复、硬解在目标笔记本上的表现、相机内参标定，
  都只在合成流上验证过。
- 未做 R1/R2/B1/B2 槽位切换（`scripts/switch_ip.sh` 是另一条线）。

## 踩过的坑（改之前先看）

1. **NV 头从偏移 16 读**，不是 12。偏移 12 是 reserved，误读会让 `frameIndex`
   变成 `streamPacketIndex`（每包都变）→ 永远凑不齐分片。
2. **`fecInfo` 的 pktIdx 是块内序号**，不是全局包序号。
3. **短帧头在重建后的数据流头部**，不是 UDP 包头部；`lastPayloadLen` 必须先由
   总长度算出来再写进头，否则截尾长度不对。
4. **`frameIndex` 必须逐帧递增**。接收端用 `_emitted` 做幽灵帧防护，同一帧号
   重复发会被全部丢弃（自测里专门有一条守这个）。
5. **新版 ffmpeg 已移除 `-vsync`**（报 `Option not found`），要用 `-fps_mode passthrough`。
6. **d3d11va 对管道裸流可能既不报错也不出帧**，进程挂着不动，必须靠外部定时器
   在 3 秒后切软解，不能只等进程退出。
7. **QPainter 画 HUD 前必须复位 GL 状态**（`glBindTexture(0)` + `glDisable(GL_TEXTURE_2D)`），
   否则 Qt 的字形纹理被视频纹理顶掉，中文整片变方块（英文数字看不出来，很难排查）。
8. **中文字体族名**：本机只有 `Microsoft YaHei UI`，写 `Microsoft YaHei` 会静默回退到
   无中文字形的字体。字号用 `setPixelSize`，`QFont` 第二参数是 pointSize（会 ×1.33）。
9. **纹理 v 坐标**：`glTexImage2D` 的第一个像素对应纹理坐标 (0,0)，所以**屏幕顶部顶点
   要取 v=0**。写反会让整幅画面上下颠倒——测试图案上下差异不明显时很难发现，
   用带地平线的场景一测就露馅。
