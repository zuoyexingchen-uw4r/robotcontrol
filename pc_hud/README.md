# 狼牙视觉 · 笔记本操控 HUD（War Thunder 风格）

电脑端操控主控：显示手机图传画面 + 本地渲染视觉叠加层（检测框/准星/提前量），
视觉设置与手机实时双向同步，**USB 手柄**操作经 WLAN 直连 ESP32-S3
（键鼠降级为后备）。

## 依赖

- Python 3.10+
- PyQt5：`pip install PyQt5`
- pygame（USB 手柄，SDL 即插即用）：`pip install pygame`
- ffmpeg（系统 PATH，或改 `~/.warhud/config.json` 的 `ffmpeg_path`）

```bash
python hud.py --check     # 检查依赖（pygame 缺失只警告，不阻塞启动）
python hud.py             # 启动
```

## 架构

```
小米手机（视觉节点）
├─ CameraStreamer 图传（H.264/HEVC + RS-FEC + pacing）──UDP 31000──┐
├─ VisionPipeline（第二 Camera2 会话 15fps）                          │
│   └─ 视觉结果 JSON ──UDP 31001 广播───────────────────────────────► │
└─ 设置快照 ──UDP 31001（500ms 心跳）──────────────────────────────► │
                                                                     ▼
笔记本电脑（本程序）                                            ┌─────────┐
├─ ffmpeg 子进程解码裸流 ──► RGB 帧 ──► 画布                      │  HUD   │
├─ 叠加层：检测框/追踪框/准星/提前量/状态面板（本地渲染）          │  窗口  │
├─ 视觉设置面板（Y 键开关）──UDP 31002 单播──► 手机写 SharedPrefs  └─────────┘
└─ USB 手柄 ──TCP 31010──► ESP32-S3 ──光电隔离 UART──► CH32X03S
    ◀──TCP 31011── 遥测（电压/电流/温度/轮速）
```

## 链路端口

| 链路 | 方向 | 端口 | 内容 |
|---|---|---|---|
| 图传 | 手机→电脑 | UDP 31000 | H.264/HEVC 裸流（RS-FEC） |
| 视觉+设置 | 手机→电脑 | UDP 31001 广播 | vision 帧 + settings 快照（500ms） |
| 设置变更 | 电脑→手机 | UDP 31002 单播 | set_req / hello |
| 操作输入 | 电脑→ESP32 | TCP 31010 | 输入帧 0xFA 0xAE（10Hz，fire 边沿） |
| 遥测 | ESP32→电脑 | TCP 31011 | 遥测帧 0xFA 0xEA（10Hz） |

帧格式详见仓库根 `PROTOCOL.md`「电脑 HUD 协议」节。

## 操作（USB 手柄为主，键鼠后备）

标准 PS/XInput 布局手柄即插即用，HUD 顶栏显示连接状态与手柄名。

| 输入 | 行为 |
|---|---|
| 左摇杆 | 底盘平移（满格 800mm/s，带死区+响应曲线） |
| 右摇杆 | 云台 yaw/pitch（满格 90°/s，速率式积分） |
| 十字键 | 底盘数字式平移（摇杆无输入时覆盖） |
| RT 扳机 | 开火（边沿触发一帧，准星闪光） |
| LT 扳机 | 精确瞄准（云台灵敏度 ×0.35） |
| A | 切换「自动开火」开关（同步到手机） |
| B | 切换追踪目标（高地靶 ↔ 基地靶） |
| X | 检测框叠加显隐 |
| Y | 视觉设置面板开关 |
| START | 比赛计时暂停/继续 |
| SELECT | 状态面板显隐 |

键鼠后备（未插手柄或手柄掉线时自动生效）：左键捕获鼠标 → 云台
0.12°/px，左键/F 开火，Esc 释放，Tab 设置面板。

> 序号不对的手柄：在 `~/.warhud/config.json` 用 `gamepad_map` 覆盖
> axis/button 序号。**注意成对覆盖**（如改了 `aim_x` 就要检查
> `aim_axis` 是否撞号——两者是不同功能）。

## 手机画面传到电脑（操作步骤）

1. **组网**：手机和电脑在同一局域网。两种方式：
   - 都连同一路由器 / WLAN；
   - **手机开便携热点，电脑连手机热点**（赛场无路由器时用这个；
     手机同时 USB 连 ESP32-S3 不影响开热点）。
2. **查电脑 IP**：电脑上 `ipconfig`，看「无线局域网适配器」的
   IPv4 地址（如 `192.168.43.37`）。
3. **启动 HUD**：`python hud.py`。默认监听 **UDP 31000**、H.264。
4. **手机配置**（APP 第二屏「图传/桥接设置」）：
   - 电脑 IP = 上一步的地址；
   - **视频端口 = 31000**（手机默认 46000，必须改，两边一致才行）；
   - 编码选 **H.264**（选 H.265 则电脑 `config.json` 里 `codec` 改 `hevc`）；
   - 分辨率 1280×720@30（默认即可）、FEC 30%。
5. **开始推流**：手机第一屏点「图传一键启停」，日志出现
   `图传启动 … → <电脑IP>:31000` 即开始；电脑 HUD 出画面。
6. **防火墙**：Windows 首次弹窗选「允许」（专用/公用网络都勾上）。

排障：HUD 显示「等待视频流…」时，按此顺序查——
① 手机/电脑是否同网段；② 端口是否都是 31000；③ 编码是否都是 H.264；
④ 电脑防火墙；⑤ HUD 顶栏「手机：--」说明 31001 也没收到包，
纯粹是网络/端口问题。

> 注意：视频链路现在即可用；**检测框/追踪框等视觉叠加要等手机端
> UDP 31001 发送端实现**（APP 侧待办，HUD 侧已就绪）。

## 配置

首次运行生成 `~/.warhud/config.json`，关键项：

- `video_port` / `codec`：与手机推流设置一致（默认 31000 / h264）
- `esp32_ip`：ESP32-S3 的 WLAN 地址
- `ffmpeg_path`：ffmpeg 可执行文件
- 手柄：`gamepad_deadzone`（0.12）、`gamepad_aim_max_dps`（90）、
  `gamepad_move_max_mmps`（800）、`gamepad_map`（序号覆盖）
